# Baby Antonopoulos

Site de memórias criado para registrar momentos especiais,
fotografias, histórias e mensagens de familiares.

## Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Bun

### Backend

- Bun
- TypeScript
- Express
- Prisma

### Banco

- PostgreSQL
- Docker Compose
